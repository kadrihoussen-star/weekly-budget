# ميزانيتي الأسبوعية

تطبيق أندرويد لإدارة الدخل الشهري: يخصم الفواتير والادخار وأقساط الديون أولًا، ثم يقسّم الباقي على **4 أسابيع** ويتتبع مصاريف كل أسبوع حسب الفئة.

## المزايا

- **4 أسابيع دائمًا**، وبداية الشهر باختيارك (مثلًا يوم استلام الراتب). كل أسبوع 7 أيام، والأسبوع الرابع يضم بقية أيام الشهر.
- **فئات أسبوعية:** النقل والغداء والمصروف الشخصي، مع إمكانية إضافة فئات جديدة بأيقونة وسقف أسبوعي اختياري.
- **الفواتير الشهرية:** مع يوم الاستحقاق وتعليم المدفوع، ونسخها من الشهر السابق بضغطة واحدة.
- **الادخار:** أهداف بمبلغ شهري مخطط، وتسجيل كل عملية ادخار وتقدّم نحو الهدف.
- **الديون:** إجمالي وقسط شهري وتسجيل التسديدات والمتبقي.
- ترحيل اختياري للمتبقي (أو العجز) بين الأسابيع، وتنبيه لوني عند الاقتراب من الحد أو تجاوزه.
- واجهة عربية من اليمين إلى اليسار، تنقّل سفلي، أيقونات لكل فئة، ووضع داكن تلقائي.
- حفظ محلي على الجهاز (Room).

## طريقة الحساب

```
المتاح للتوزيع = الدخل − (فواتير الفترة + أقساط الديون + الادخار الشهري)
ميزانية الأسبوع = المتاح للتوزيع ÷ 4   (+ المرحّل من الأسبوع السابق إن فُعّل)
```

## بناء التطبيق

يبني GitHub Actions ملف APK عند كل رفع إلى `main`: افتح تبويب **Actions**، واختر آخر تشغيل، وحمّل `weekly-budget-debug-apk` من قسم **Artifacts**.

> كل بناء يُوقَّع بمفتاح تجريبي مختلف، لذا احذف النسخة القديمة من الهاتف قبل تثبيت نسخة جديدة.

## التقنيات

Kotlin، Jetpack Compose (Material 3)، Room، MVVM مع StateFlow. الحد الأدنى: Android 8.0 (API 26).
