# ميزانيتي الأسبوعية

تطبيق أندرويد لإدارة الدخل الشهري، يقسّم دخل الشهر على عدد أسابيعه ويتتبع المصاريف أسبوعًا بأسبوع.

## المزايا

- تحديد دخل كل شهر على حدة، والتنقل بين الأشهر.
- تقسيم الدخل بالتساوي على أسابيع الشهر (4 أو 5 أسابيع): الأيام 1-7، 8-14، 15-21، 22-28، ثم 29 حتى نهاية الشهر.
- ترحيل اختياري للمتبقي (أو العجز) من أسبوع إلى الذي بعده.
- بطاقة لكل أسبوع: الميزانية، المرحّل، المصروف، المتبقي، وشريط تقدّم يتلوّن عند الاقتراب من الحد أو تجاوزه.
- إضافة المصاريف بالفئة واليوم والملاحظة، وحذفها.
- حفظ محلي على الجهاز (Room)، واجهة عربية من اليمين إلى اليسار، ووضع داكن تلقائي.

## التقنيات

Kotlin، Jetpack Compose (Material 3)، Room، MVVM مع StateFlow. الحد الأدنى: Android 8.0 (API 26).

## بناء التطبيق

**عبر GitHub Actions (دون Android Studio):** ارفع المشروع إلى المستودع، ثم افتح تبويب **Actions**، واختر آخر تشغيل لـ *Build APK*، وحمّل الملف من قسم **Artifacts** (`weekly-budget-debug-apk`).

**عبر Android Studio:** افتح مجلد المشروع، وانتظر مزامنة Gradle، ثم اضغط Run.

## تخصيص

- العملة: الثابت `CURRENCY` في `ui/BudgetScreen.kt` (الافتراضي «دج»).
- الفئات: القائمة `Categories` في الملف نفسه.
- طريقة التقسيم: الدالة `computeWeeks` في `domain/WeekCalc.kt`.
